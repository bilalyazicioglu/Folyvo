# Security policy

## Supported versions

Folyvo has not had a release yet. Once it does, security fixes are made for the latest released version.

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

- Use GitHub's private reporting: <https://github.com/bilalyazicioglu/Folyvo/security/advisories/new>
- Or write to security@bilalyazicioglu.com

Include what you found, how to reproduce it, and which version or commit you tested. You will get a reply within a week. Please give us a reasonable time to ship a fix before you publish details; we will credit you in the release notes unless you prefer otherwise.
