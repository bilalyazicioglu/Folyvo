The first Folyvo you can download. It is early: expect rough edges, and keep your usual backups while you try it.

## Install

1. Download **Folyvo_0.0.1_universal.dmg** below and drag Folyvo to Applications. It runs on macOS 14 or later, on Apple silicon and Intel Macs.
2. This build is not signed by Apple yet ([#27](https://github.com/bilalyazicioglu/Folyvo/issues/27)), so macOS stops it the first time. Open it once, then go to **System Settings › Privacy & Security**, find the line about Folyvo being blocked and choose **Open Anyway**.
3. Choose a folder. Folyvo lives in the menu bar from then on.

Run it from Applications. Opened from Downloads or from the disk image, it cannot update itself and says so.

## What it does

- Keeps a version each time a file in your folder is saved, in Word, Excel or any other app.
- Shows what changed between saves, and the file as it was at any saved time. Restore it, or open a copy.
- Notes which version you sent through Mail, AirDrop or Messages.
- Tells you which saved version a file is: right-click it in Finder › Which One Is This?
- Stays small: every save from the last 14 days, then one a day. Saves you marked, sent or wrote a note on always stay. It asks before letting any go.

Everything stays on your Mac. There is no account.

## Updates

Once a day Folyvo asks GitHub whether a newer version exists, and says so in the menu bar. Nothing is installed until you choose **Install and Restart**. Each update is signed, and checked against that signature before it is installed. The request carries nothing about you or your files; you can turn it off in the window that shows how much room Folyvo takes.

If macOS asks again for access to a folder after an update, allow it. This stops once Folyvo is signed by Apple.

## Checking the download

`SHA256SUMS` lists the files' checksums. In the folder you downloaded them to: `shasum -a 256 -c SHA256SUMS`.
