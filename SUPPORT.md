# Getting help

- Questions and ideas: start a thread in [Discussions](https://github.com/bilalyazicioglu/Folyvo/discussions).
- Bugs: open an [issue](https://github.com/bilalyazicioglu/Folyvo/issues/new/choose) and fill in the form.
- Security problems: follow [SECURITY.md](SECURITY.md); please do not use public issues.
